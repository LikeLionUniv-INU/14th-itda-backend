# 잇다(ITDA) 유저플로우 문서

> **버전**: v2.0  
> **작성일**: 2026-08-11  
> **목적**: 와이어프레임 + 요구사항 명세서 기반 전체 사용자 흐름 정의 — API 명세 및 ERD 설계의 기초 자료  
> **v2.0 변경사항**: 요구사항 명세서 10건 반영, 프론트/백엔드 요구사항 분리 정리, 상의 필요 항목 표기

---

## 1. 서비스 개요

**잇다(ITDA)**는 다국적 팀이 함께 문서(스토리보드 등)를 작성하고, AI 번역을 통해 각 팀원의 언어로 자동 번역된 버전을 공유하는 협업 플랫폼이다.

### 핵심 가치
- **팀 프로젝트 기반 협업**: 팀을 만들고, 초대 코드로 팀원을 모아 함께 작업
- **문서 작성 도구**: 스토리보드 형태의 구조화된 문서(화면 정보 + 와이어프레임 + 요구사항)를 페이지 단위로 작성
- **AI 다국어 번역**: 작성 완료된 문서를 팀원의 국적/언어에 맞게 자동 번역하여 공유
- **버전 관리**: 문서 수정 시 버전이 올라가고, 변경 이력을 추적

---

## 2. 사용자 역할 정의

| 역할 | 설명 |
|------|------|
| **비로그인 사용자** | 회원가입 또는 로그인만 가능 |
| **일반 사용자 (로그인 후)** | 팀 생성/참여, 메인 대시보드 이용 |
| **팀장 (팀 생성자)** | 팀 프로젝트를 생성한 사용자. 초대 코드 생성/공유, **문서 생성 권한** 보유 |
| **팀원** | 초대 코드로 팀에 참여한 사용자. 번역된 문서를 확인 (문서 생성 권한 없음) |

## 3. 전체 유저플로우 요약

```
[회원가입] → [로그인] → [메인 대시보드 (홈/프로젝트/문서/설정 탭)]
                              │
                ┌─────────────┼─────────────┐
                ▼             ▼             ▼
        [팀 프로젝트       [팀 프로젝트     [설정]
          생성 모달]        참여 모달]
                │             │
                ▼             │
        [초대코드 노출       │
          모달]              │
                │             │
                └──────┬──────┘
                       ▼
              [팀 프로젝트 메인화면]
                       │
                       ▼ (팀장만)
              [문서 생성 모달
               (유형선택→정보입력→완료)]
                       │
                       ▼
              [문서 작성 (팀장)]
                       │
                       ▼
              [작성 완료 확인 모달]
                       │
                       ▼
              [AI 번역 안내 모달]
                       │
                       ▼
              [팀원 언어 선택 모달]
                       │
                       ▼
              [AI 번역 진행중 화면]
                       │
                       ▼
              [번역 완료 → 3초 후 팀프로젝트 메인으로 이동]
                       │
          ┌────────────┼────────────┐
          ▼                         ▼
  [팀장: 문서 수정]          [팀원: 문서 확인 (읽기 전용)]
          │
          ▼
  [수정 저장 → AI 재번역]
```

### 4.1 회원가입 (Sign Up)

**화면**: `회원가입.png`  
**요구사항 명세서**: `요구사항명세서/회원가입.png`

#### 프론트엔드 요구사항

| 필드 | 규칙 |
|------|------|
| **이름 (성/이름 분리)** | 영어로만 입력. 영어 외 문자 입력 시 → "영어 이름으로 작성해주세요." |
| **이메일** | 메일 형식 검증. 형식 아닐 경우 → "올바른 이메일 형식이 아닙니다" |
| **비밀번호** | 8~16자의 영문, 숫자 조합. 조건 불충족 시 → "8~16자의 영문, 숫자 조합으로 입력해주세요." |
| **비밀번호 확인** | 비밀번호와 동일한 값 입력. 불일치 시 → "비밀번호가 일치하지 않습니다." |
| **국가 선택** | 드롭다운으로 국가 선택 |
| **사용 언어 선택** | 드롭다운으로 주요 사용 언어 선택 |
| **회원가입 버튼** | 모든 입력 완료 & 오류 없을 때만 활성화 |

#### 흐름
1. 사용자가 회원가입 페이지에 접근
2. 성(Last name) / 이름(First name) **영어로** 입력
3. 이메일, 비밀번호, 비밀번호 확인 입력
4. 국가 선택 (드롭다운)
5. 사용 언어 선택 (드롭다운)
6. **"회원가입"** 버튼 클릭
7. 회원가입 완료 → **로그인 페이지로 이동**

#### 백엔드 요구사항
- **입력 데이터**: 이름(성/이름) / 이메일 / 비밀번호 / 국적 / 사용언어
- 비밀번호 해싱 후 저장
- 이메일 중복 검사

### 4.2 로그인 (Login)

**화면**: `로그인.png`  
**요구사항 명세서**: `요구사항명세서/로그인.png`

#### 프론트엔드 요구사항

| 필드 | 규칙 |
|------|------|
| **이메일 input** | 미입력 시 Enter/로그인 버튼 → "이메일을 입력해주세요." / 형식 아닐 경우 → "올바른 이메일 형식이 아닙니다" |
| **비밀번호 input** | 미입력 시 → "비밀번호를 입력해주세요" / 틀렸을 시 → "알맞은 비밀번호를 입력해주세요." / 마스킹 처리 (●●●●) |
| **로그인 버튼** | 이메일과 비밀번호 모두 입력되면 활성화 |
| **회원가입 버튼** | 회원가입 페이지로 이동 |

#### 흐름
1. 이메일 입력
2. 비밀번호 입력
3. **"로그인"** 버튼 클릭
4. 인증 성공 → JWT 토큰 발급 → **메인 대시보드로 이동**
5. 인증 실패 → 에러 메시지

#### 백엔드 요구사항
- **조회 데이터**: 이메일 / 비밀번호
- JWT 토큰 발급 및 반환

### 4.3 메인 대시보드 (Main Dashboard)

**화면**: `메인화면홈데이터있을때.png` 외  
**요구사항 명세서**: `요구사항명세서/메인화면.png`

#### 네비게이션
- **4개 탭**: 홈 / 프로젝트 / 문서 / 설정
- 우측 상단: 로그인한 유저의 **이니셜** 표시 (성의 이니셜로 처리. 예: 김서연 → 김)
- **[프로젝트 생성]** 버튼 → 프로젝트 생성 모달 창 띄우기
- **[프로젝트 입장]** 버튼 → 초대코드 입력 모달 창 노출

#### 배너
- "안녕하세요, OOO님" → 로그인한 유저의 이름 정보 가져와서 대치

#### 4.3.1 홈 탭 — 내 프로젝트 섹션

백엔드로부터 조회해서 데이터 띄우기:
- **프로젝트 이름**
- 프로젝트 안 **팀원들이 사용하는 언어들**
- 프로젝트 안 **팀원 정보** (성/이름 정도만)
- 이 프로젝트 안에서 **문서가 업데이트 된 시간** (현재시간 - 업데이트 시간)

데이터 없을 시 → '메인화면 데이터 없을 때 화면' 처럼 디자인  
프로젝트 클릭 시 → **'팀프로젝트 메인화면'**으로 이동

#### 4.3.2 홈 탭 — 최근 문서 섹션

내가 참여한 프로젝트들에 가지고 있는 문서들 정보 노출:
- **문서 이름** / 해당 프로젝트 / 작성된 문서의 **언어** / **version** / 업데이트 된 시간 (현재시간 - 업데이트 시간)

데이터 없을 시 → 빈 상태 디자인  
문서 아이템 클릭 시 → 해당 문서 조회하는 화면으로 이동

#### 4.3.3 프로젝트 탭 / 문서 탭
- (홈 탭의 내 프로젝트/최근 문서와 동일한 데이터를 각각 전체 목록으로 표시)

#### 알림
- **(상의 필요)** — 알림 기능 범위 미정

#### 백엔드 요구사항
- **조회 데이터**:
  - 이름 (성/이름)
  - 유저가 참여하고 있는 프로젝트 정보 → 프로젝트 이름 / 팀원들 사용 언어 / 팀원 정보(성/이름) / 문서 업데이트 시간
  - 유저가 포함된 프로젝트 내 문서들 정보 → 문서 이름 / 해당 프로젝트 / 작성 언어 / version / 업데이트 시간
- **알림** — **(상의 필요)**

### 4.4 팀 프로젝트 생성 (팀 생성)

**화면**: `팀프로젝트생성1.png`, `팀프로젝트생성2.png`  
**요구사항 명세서**: `요구사항명세서/팀생서.png`

#### 프론트엔드 요구사항

**[새 프로젝트 생성 모달]**:
| 필드 | 규칙 |
|------|------|
| **프로젝트 이름** | 필수. 미입력 시 "프로젝트 이름을 입력해주세요." |
| **프로젝트 기본 언어** | 드롭다운 선택. 일단 **한국어만 활성화**, 나머지 언어 비활성화 **(상의)** |
| **[프로젝트 생성] 버튼** | 모든 입력사항 입력 시 활성화 |
| **[닫기] 버튼** | 모달창 닫기 |

**[초대코드 노출 모달]**:
- [프로젝트 생성] 버튼 누르면 → 초대코드 노출 → 백엔드로 코드 요청
- 백엔드로부터 **6자리 코드** 받아서 노출
- **복사하기** 버튼 → 클립보드에 복사

**[초대코드 모달 닫기 버튼 누르면]**:
- 메인화면을 리로딩하여 '내 프로젝트' 컴포넌트에 새로 생성된 팀프로젝트 카드 띄우기

#### 흐름
1. 메인 대시보드에서 **[프로젝트 생성]** 버튼 클릭 → 모달 오픈
2. 프로젝트 이름 입력
3. 기본 언어 선택 (현재 한국어만)
4. **[프로젝트 생성]** 클릭 → 백엔드에서 프로젝트 생성 + 초대코드 생성
5. 초대코드 모달 표시 → 복사 가능
6. 닫기 → 메인화면 리로드 (새 프로젝트 카드 노출)

#### 백엔드 요구사항
- **로직**: 프론트로부터 프로젝트 이름 및 기본언어 정보를 받아 새 프로젝트 생성. 초대코드는 **영어 대문자 / 숫자 조합으로 6자리 랜덤** 생성
- **입력**: 프로젝트 이름 / 기본언어
- **조회**: 팀프로젝트의 초대 코드 조회

### 4.5 팀 프로젝트 참여

**화면**: `팀프로젝트참여.png`  
**요구사항 명세서**: `요구사항명세서/팀생서.png` (팀 입장 부분 포함 추정)

#### 흐름
1. 메인 대시보드에서 **[프로젝트 입장]** 버튼 클릭 → 초대코드 입력 모달
2. **6자리 초대 코드** 입력
3. **"참여하기"** 클릭
4. 유효 → 팀원으로 등록 → 팀 프로젝트 메인 화면으로 이동
5. 무효 → 에러 메시지

#### 유효성 검사
- 초대 코드 존재 여부
- 이미 참여 중인 팀 중복 검사

### 4.6 팀 프로젝트 메인 화면

**화면**: `팀프로젝트메인화면.png`  
**요구사항 명세서**: `요구사항명세서/팀프로젝트메인화면.png`

#### 프론트엔드 요구사항

**[네비게이션]**:
- **팀장 화면에서만** [문서 생성] 버튼 노출 / 팀원 화면에서는 미노출
- [나가기] 누르면 메인 화면으로 이동

**[배너]**:
- 팀프로젝트 이름
- 팀장이 설정한 **팀프로젝트 기본 언어**
- 참여자 이름 (성 이니셜만 가져와서) → **3개까지** 노출, 그 이상은 **+1, +2**로 처리
- 프로젝트 생성 년월일

**[최근 문서]**:
- 내가 참여한 프로젝트들에 가지고 있는 문서들 정보 노출
  → 문서 이름 / 해당 프로젝트 / 작성된 문서의 언어 / version / 업데이트 된 시간
- 데이터 없을 시 → '팀프로젝트 메인화면-아직 데이터 없을 시' 디자인
- 문서 아이템 클릭 시 → 해당 문서 조회 화면으로 이동

**[활동 요약]**:
- 작성자 이름/이니셜
- "문서 이름 / version이 업로드 되었습니다." & 현재시각 - 업데이트 시간

**[프로젝트 멤버]**:
- 해당 프로젝트에 참여한 사람들 목록
- 이름(이름/성)
- 각 팀원들의 역할 (**팀장 / 팀원**)
- **멤버 초대하기** 클릭 시 → 팀프로젝트 생성화면과 같은 초대코드 노출 모달 창 띄우기

**[문서 모아보기]**:
- 해당 프로젝트 내에 있는 **전체 문서들**
- 문서이름 / 작성된 문서의 언어 / version / 업데이트 된 시간
- 같은 문서의 버전이 여러개 있는 경우 → 드롭다운으로 버전 선택해서 보기 / default는 **최근 버전**으로 표시
- 문서 클릭 시 → **'문서 확인'** 페이지로 이동

#### 백엔드 요구사항
- **조회 데이터**:
  - 프로젝트 이름
  - 해당 프로젝트 참여 인원 정보 → 이름(성/이름) / 역할(팀장/팀원, 프로젝트 생성한 사람이 팀장)
  - 해당 프로젝트 정보 → 프로젝트 이름 / 기본 언어 / 팀원들 사용 언어 / 팀원 정보(성/이름) / 프로젝트 생성 년월일
  - 해당 프로젝트 내 전체 문서들 → 문서 이름 / 작성 언어 / version / 업데이트 시간
  - 최근에 업데이트 된 문서의 정보 → 문서 이름 / version / 업데이트 시간 / 작성자 이름

### 4.7 문서 생성 (팀장만 가능)

**화면**: `프로젝트생성문서유형선택.png`, `프로젝트생성문서정보입력.png`, `프로젝트생성문서생성완료.png`  
**요구사항 명세서**: `요구사항명세서/문서생성페이지.png`

#### 프론트엔드 요구사항

**[문서 유형 선택 모달]**:
- 일단 **스토리보드 버튼만 활성화** (나머지 비활성화)
- 스토리보드 버튼 누르면 → '기본정보 입력' 모달창으로 넘어가기
- [x] 버튼 → 모달창 닫기

**[기본정보 입력 모달]**:
| 필드 | 규칙 |
|------|------|
| **문서 이름** | 최대 **10자** |
| **언어** | 드롭다운 선택. 일단 **한국어만 활성화** **(상의)** |
| **버전** | default로 **1**로 입력 (숫자로만 입력) |
| **[취소]** | 모달 창 닫기 |
| **[생성]** | '생성완료' 모달창으로 이동 |

**[문서 생성 완료 모달]**:
- 문서이름 / 언어 / 버전 정보 노출

#### 흐름
1. 팀프로젝트 메인에서 **[문서 생성]** 클릭 (팀장만 보임)
2. 문서 유형 선택 → 스토리보드
3. 기본정보 입력: 문서 이름(10자), 언어, 버전(기본 1)
4. [생성] 클릭 → 문서 생성 완료 모달 → 문서 작성 화면으로 이동

#### 백엔드 요구사항
- **입력**: 문서이름 / 언어 / 버전 정보 받아 문서 생성

### 4.8 문서 작성 (스토리보드) — 팀장

**화면**: `프로젝트작성데스크톱와이어프레임.png`, `프로젝트작성모바일와이어프레임.png`, `프로젝트작성데이터없을때.png`  
**요구사항 명세서**: `요구사항명세서/문서작성.png`

이것이 잇다의 **핵심 기능**이다.

#### 프론트엔드 요구사항

**[상단바]**:
- **[←] 버튼** → '팀 프로젝트 메인화면'으로 이동
- [+] 버튼 → "저장하지 않고 나갈 때-모달창" 띄우기
- 문서이름 / Version 정보 가져와서 `{문서이름}_Version.{version}` 형태로 노출
- **[임시저장]** 버튼 — 아직까지 작업중이던 것을 상태 저장
- **[저장]** 버튼 → '저장하는 놀이공원 해 모달 같은 것으로 이동'

**[페이지 선택]**:
- [페이지 추가] 버튼 누르면 새로운 탭 생성과 동시에 와이어프레임/요구사항 작성 폼 노출
- '화면정보'에서 화면 이름을 작성하면 [페이지 선택 탭]에 (페이지 번호) 탭 제목 반영
- 탭 제목를 1번즈 줄여야하기 때문, "화면정보" → "화면이름을 입력하면 타블릿 이름 [(1)회원가입] 페이지 반 페이지로 노출

**[화면정보]**:
| 필드 | 규칙 |
|------|------|
| **화면 이름** | 최대 **10자 이내** 입력 |
| **화면 ID** | 최대 **10자 이내** 입력 |

**[와이어프레임]**:
- 드래그 or 클릭 시 와이어프레임 이미지 업로드 가능
- **드래그/드롭** 또는 "데스크톱" or "모바일" 선택
- **데스크톱 규격**: 업로드 해상도 자유, 리사이즈 → 가로 **660px** 고정. 원본이 660x370 → 세로 사이즈가 660을 넘으면 370을 세로비율 맞춰서 리사이즈 (세로 사이즈가 커져서 스크롤)
- **모바일 규격**: 업로드 해상도 자유, 리사이즈 → 가로 **214px** 고정 (기본 214x463, 가로 사이즈는 214로 고정)
- 새로 사이즈가 바뀌면 → 새로 사이즈가 뭐든 → 해당 이미지를 규격에 맞게 리사이즈

**[핀 추가/삭제]**:
- 와이어프레임 이미지 업로드 후 핀 추가 버튼 활성화 (이전에는 비활성)
- [핀 추가] 버튼 누르고 와이어프레임 이미지 위에 클릭 시 핀 스티커 추가 (이미지 위에만 가능, 이미지 밖이면 못함)
- 이미지 내에서 **x, y 좌표 값이 같이 저장**되어서 핀에 매핑 표현되도록
- [핀 추가]와 동시에 **'요구사항 작성'** 안에 해당 핀의 스티커 번호 반영
- 핀 자동 번호 할당: **1, 2, 3, 4번** 스티커가 있으면 3번 이후에 자동 4번에서 자동 부여, 3번이면 4번도 자동
- 생성된 핀 **드래그로 위치 조정** 가능
- [이미지 변경] 버튼 → 클릭 시 새 이미지로 교체 가능

**[요구사항 작성]**:
- **탭 구성**: 공통 / 기획 / 프론트 / 백엔드 / 디자인
- 각 **탭마다 핀은 같은 번호** (핀 번호는 탭 간 공유, 각 탭 안에서 요구사항만 다르게 작성)
- No. = 핀 번호 (탭 변경해도 핀은 동일)
- 항목: 최대 **10자**까지 입력 가능
- 요구사항: 최대 **200자**까지 입력 가능 (입력 영역이 200자 넘으면 해당 영역 안에서 계속 늘어남 수 있게)
- 새로 칸이 갈 수 있어야 하는 요구사항 작성 컴포넌트를 넘어서면 탭바 아래로 스크롤 됨

**[팀원 번역 언어 선택 팝업]** (저장 시):
- 해당 팀프로젝트에 팀원의 정보 (이름 / 국적 / 사용언어) 데이터 조회하고 가져오기
- 드롭다운 언어 선택 → default 선택 → 해당 유저의 사용언어의 정보를 그것을 가져오기
- [작성완료] 버튼 → [번역] 페이지로 이동

**[사용 언어]**:
- 백엔드로부터 해당 문서에 사용 언어 정보 가져와서 그 언어로 문서 구성 (한국어면 한 구성)

#### 백엔드 요구사항
- **입력**:
  - 문서이름 / 사용언어 / version
  - 해당 팀프로젝트 내에 있는 인원들 정보(이름 / 국적 / 사용언어)
- **저장** (페이지별):
  - 페이지 번호 / 화면 이름 / 화면 ID / 와이어프레임 이미지 / 핀 번호 / 핀 좌표(x,y) / 항목 / 요구사항
  - **기획 / 프론트 / 백엔드 / 디자인 탭마다 다른 핀으로 처리할 것인지 상의 필요**

### 4.10 AI 번역

**[Progress bar]**:

**[번역 언어 항목]**:

- 선택한 언어의 개수가 **3개를 넘어가면** 좌우로 넘길 수 있게 버튼 활성화

**[100%가 되었을 때]**:
- "전체 문서의 번역이 완료되었습니다." **3초간** 메시지 노출

#### 백엔드 요구사항

- **입력**: 번역 완료 후 해당 문서들을 **팀 프로젝트 내에 저장**

### 4.11 문서 수정 (팀장 — 버전 관리)

**화면**: `문서수정.png`  
**요구사항 명세서**: `요구사항명세서/문서수정.png`

#### 프론트엔드 요구사항

**[상단바]**:
- [←] 버튼 → 팀 프로젝트 메인화면으로 이동
- [임시저장] → 작업 중 상태 저장
- 문서이름_Version.{version} + **"수정 중"** 노출

**[요구사항 수정]**:
- 요구사항 작성 → 해당 버전의 요구사항만 표시 (기존 내용 + 새로운 것 가져와서 표시)
- 수정 내용이 빈칸이면 → "수정내용을 입력해주세요" 표시, 빈칸이면 저장 안됨
- 수정 시 해당 내용 마이라이팅 → 기존 내용 보이고 "수정하기" 버튼으로 변경
- 수정 상태 마이라이팅이 되면 → 수정하기 버튼 옆에 **[취소하기]** 버튼 활성화
- 수정이 안 되는 항목: "수정하기" 버튼이 비활성화 된 채로 노출
- 각 요구사항별 **[수정하기]** 버튼

**[수정사항 목록]** (우측 패널):
- 수정된 요구사항 리스트 표시
- 수정된 내용만 하이라이팅 + ver 정보 + 수정 시간

**[와이어프레임 수정]**:
- 문서 작성과 동일한 와이어프레임 규격/핀 기능

**[팀원 번역 언어 선택]** — 문서 작성과 동일

**[버전 변경 이력]** (하단):
- 테이블: 버전 / 작성자 / 작성일 / 변경 내용 / 비고
- 예: ver.2 / 수정 중 / 김서연 / 2026.05.20 14:30 / 요구사항 3건 수정

**[삭제]**:
- 해당 버전의 데이터 삭제
- 삭제 후 → 이전 버전이 최신 버전으로 승격

#### 백엔드 요구사항
- **조회**:
  - 문서이름 / 언어 / version
  - 페이지 번호 / 화면 이름 / 화면 ID / 와이어프레임 이미지 / 핀 번호 / 핀 좌표 / 항목 / 요구사항
  - 기존 버전 이력 정보
- **입력**:
  - 수정된 요구사항 / 와이어프레임 / 핀 데이터를 **새 버전**으로 저장
  - 수정 이력 기록 (작성자, 변경 내용, 시간)
- **삭제**:
  - 해당 version 삭제 → 삭제하면 그 이전 버전이 최신
  - 수정된 데이터만 삭제, 이전 버전 보존

## 5. 플로우별 상태 전이

### 5.1 문서 상태

```
[작성 중 (Draft)] → [임시저장 (Auto-saved)] → [작성 완료 (Completed)]
                                                       │
                                                       ▼
                                              [번역 중 (Translating)]
                                                       │
                                                       ▼
                                              [번역 완료 (Translated)]
                                                       │
                                              3초 후 팀프로젝트 메인 이동
                                                       │
                                                       ▼
                                              [수정 중 (Editing)] → [새 버전 저장] → [재번역]
                                                                          │
                                                                   [버전 삭제] → 이전 버전 승격
```

### 5.2 번역 상태 (언어별)

```
[대기 중 (Pending)] → [번역 중 (Translating)] → [완료 (Completed)]
```

## 6. 화면-기능 매핑 정리 (백엔드 중심)

| # | 화면 | 백엔드 처리 | 입력 데이터 | 조회 데이터 |
|---|------|----------|----------|----------|
| 1 | 회원가입 | 계정 생성 | 이름(성/이름), 이메일, 비밀번호, 국적, 사용언어 | - |
| 2 | 로그인 | 인증+JWT | - | 이메일/비밀번호 검증 → JWT 반환 |
| 3 | 메인 대시보드 | 데이터 조회 | - | 이름, 프로젝트 목록(이름/언어/팀원/업데이트시간), 문서 목록(이름/프로젝트/언어/version/업데이트시간) |
| 4 | 팀 프로젝트 생성 | 프로젝트+초대코드 생성 | 프로젝트 이름, 기본언어 | 초대코드 반환 |
| 5 | 팀 프로젝트 참여 | 팀원 등록 | 초대코드 | 코드 유효성 검증 |

## 9. 용어 정의

| 용어 | 설명 |
|------|------|
| **팀 프로젝트** | 여러 팀원이 함께 작업하는 단위. 초대 코드로 팀원을 모집. 생성자가 팀장 |
| **문서** | 팀 프로젝트 내에서 생성되는 작업 단위. 문서 유형(스토리보드)을 선택하여 생성 |
| **스토리보드** | 문서 유형 중 하나. 화면별 와이어프레임과 요구사항을 구조화한 문서 |
| **페이지** | 스토리보드 내의 개별 화면 단위 (예: 회원가입 페이지, 로그인 페이지) |
| **핀(Pin)** | 와이어프레임 이미지 위에 배치하는 번호 마커. x,y 좌표 저장. 요구사항과 매핑 |
| **요구사항** | 각 핀에 대응하는 기능/디자인 명세. 역할별(공통/기획/프론트/백엔드/디자인)로 분류 |
| **버전** | 문서 수정 시 자동 생성되는 이력 단위 (ver.1, ver.2, ...). 삭제 시 이전 버전 승격 |
| **AI 번역** | 작성 완료된 문서를 팀원의 언어로 자동 번역하는 기능 |
| **초대 코드** | 팀 프로젝트 생성 시 자동 발급되는 **영어 대문자+숫자 6자리** 코드 |
| **팀장** | 팀 프로젝트를 생성한 사용자. 문서 생성/수정 권한 보유 |
| **팀원** | 초대 코드로 참여한 사용자. 문서 확인(읽기 전용) 권한 |
